# ML Pipeline Directory

Taruh skrip pipeline preprocessing, feature engineering, atau training di folder ini.

## File yang direkomendasikan:
1. `preprocessing.py` - Logika pembersihan data dan filtering sinyal.
2. `features.py` - Logika ekstraksi fitur statistika/frekuensi dari sinyal PPG & IMU.
3. `train.py` - Skrip opsional jika ingin melakukan training ulang model lokal.
